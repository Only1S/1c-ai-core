# ones-core — Claude Code для разработки на 1С

Плагин для Claude Code. С ним Claude работает с конфигурацией 1С как аккуратный разработчик. Факты он берёт из справки по платформе, стандартов и индекса кода, а не из памяти. Каждый изменённый модуль он проверяет, опасные команды плагин запрещает.

## Как подключить

Понадобятся Claude Code, Git, Python 3.8 или новее, Java 17 или новее и платформа 1С 8.3.

В папке проекта выполните:

```bash
claude plugin install ones-core --marketplace Only1S/1c-ai-core --scope project
```

Затем откройте проект в Claude Code и наберите `/ones-core:setup`. Команда спросит папку выгрузки конфигурации и платформу. Перед изменениями она покажет их список и дождётся вашего «да».

## Что умеет

- **Скиллы** — метаданные, управляемые и обычные формы, роли, отчёты СКД, макеты, расширения, запросы, БСП, выгрузка и загрузка конфигурации.
- **Проверка модулей** — каждый изменённый модуль `.bsl` сразу проверяет анализатор, ошибку Claude исправляет.
- **Защита** — отказ на опасные команды git, удаление файлов и работу с незарегистрированной базой.
- **Справка** — стандарты 1С, методы и типы платформы, индекс кода вашей конфигурации.
- **Тесты** — юнит-тесты YAXUnit и сценарии Vanessa на тестовой базе, команда `/ones-core:tests`.

Подробно — в [plugin/docs/core/plugin-in-project.md](plugin/docs/core/plugin-in-project.md).

## Обновление

```bash
claude plugin marketplace update ones-core
claude plugin update ones-core@ones-core --scope project
```

Затем перезапустите Claude Code. Что изменилось в каждой версии — в [RELEASES.md](RELEASES.md).

## Если что-то не так

Наберите `/ones-core:report-issue` или откройте Issue на этой странице.

Установка падает с `Filename too long` — разрешите git длинные пути и повторите установку:

```bash
git config --global core.longpaths true
```
