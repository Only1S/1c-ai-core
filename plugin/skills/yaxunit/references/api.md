# Справочник API YAxUnit 25.12

Экспортные методы публичных модулей движка, собранные из поставки `YAxUnit-25.12.cfe` (распаковка `cf-unpack`, 30.10.2026) — сигнатура и первая строка описания автора. Источник — bia-technologies/yaxunit, лицензия Apache-2.0. Точка входа — общий модуль `ЮТест`: `ЮТест.ОжидаетЧто` возвращает `ЮТУтверждения`, `ЮТест.ОжидаетЧтоТаблицаБазы` — `ЮТУтвержденияИБ`, `ЮТест.Данные()` — `ЮТТестовыеДанные`. Регистрация тестов — `ЮТТесты` в процедуре `ИсполняемыеСценарии()` без параметров.

## ЮТест
- `ОжидаетЧто(ПроверяемоеЗначение, Сообщение = "")` — Возвращает API формирования утверждения для проверки теста.
- `ОжидаетЧтоТаблицаБазы(ИмяТаблицы, Сообщение = "")` — Возвращает API формирования утверждения для проверки данных базы.
- `Данные()` — Возвращает API для работы с тестовыми данными.
- `Предикат(Условия = Неопределено)` — Возвращает API для формирования предикатов/утверждений, которые могут быть использованы для проверки коллекций.
- `Варианты(Реквизиты)` — Конструктор вариантов прогона теста.
- `Контекст()` — Умный контекст, в который можно сохранять и получать из него промежуточные данные
- `Пропустить(Сообщение = Неопределено)` — Пропустить выполнение теста.
- `Упал(СообщениеОбОшибке = "Тест явно завершен с ошибкой", ФактическоеЗначение = Неопределено, ОжидаемоеЗначение = Неопределено)` — Вызывает явное падение теста.
- `КонтекстТеста()` — Возвращает структуру, в которой можно хранить данные используемые в тесте.
- `КонтекстТестовогоНабора()` — Возвращает структуру, в которой можно хранить данные используемые в тестах набора.
- `КонтекстМодуля()` — Возвращает структуру, в которой можно хранить данные используемые в тестах модуля.
- `Пауза(Время)` — Приостанавливает поток выполнения на указанное количество секунд
- `ВывестиВКонсоль(Сообщение)` — Выводит сообщение в консоль (stdout) приложения
- `ДобавитьСообщение(ТекстСообщения)` — Добавляет сообщение в лог исполнения теста.
- `ДобавитьПредупреждение(ТекстПредупреждения)` — Добавляет предупреждение в лог исполнения теста.
- `Зависимость(ОписаниеЗависимости)` — Возвращает данные зависимость.
- `Окружение()` — Возвращает информацию об окружении.
- `ОписаниеТекущегоТеста()` — Возвращает описание текущего теста
- `ОписаниеТекущегоТестовогоНабора()` — Возвращает описание текущего теста
- `ОписаниеТекущегоТестовогоМодуля()` — Возвращает описание текущего тестового модуля

## ЮТТесты
- `ДобавитьТестовыйНабор(Имя, ТегиСтрокой = "")` — Создает и регистрирует тестовый набор, в который будут добавляться последующие тесты
- `Тег(Тег)` — Добавляет тег к тесту/набору/модулю
- `ДобавитьТест(ИмяТестовогоМетода, ПредставлениеТеста = "", ТегиСтрокой = "", Контексты = Неопределено)` — Регистрирует тест, исполняемый в контекстах, в которых доступен тестовый модуль.
- `ДобавитьКлиентскийТест(ИмяТестовогоМетода, ПредставлениеТеста = "", Теги = "")` — Регистрирует тест исполняемый на клиенте.
- `ДобавитьСерверныйТест(ИмяТестовогоМетода, ПредставлениеТеста = "", ТегиСтрокой = "")` — Регистрирует тест исполняемый на сервере.
- `СПараметрами(Параметр1 = "_!%*", …, Параметр10 = "_!%*")` — Устанавливает параметры вызова теста. Первый вызов задаёт параметры, каждый следующий добавляет ещё один тест с параметрами: один тест на много входных значений, `ЮТТесты.ДобавитьТест("Тест1").СПараметрами(1).СПараметрами(2)`
- `СПараметрамиНаКлиенте(Параметр1 = "_!%*", …, Параметр10 = "_!%*")` — Устанавливает параметры вызова теста и новый контекст исполнения (клиентский).
- `СПараметрамиНаСервере(Параметр1 = "_!%*", …, Параметр10 = "_!%*")` — Устанавливает параметры вызова теста и новый контекст исполнения (серверный).
- `НастройкаИсполнения(ИмяПараметра, Значение)` — Устанавливает настройку выполнения тестового метода.
- `ВТранзакции(ВыполнятьВТранзакции = Истина)` — Устанавливает настройку выполнения тестового метода в транзакции.
- `УдалениеТестовыхДанных(УдалятьСозданныеДанные = Истина)` — Устанавливает настройку удаления созданных тестовых данных
- `Перед(ВыполнитьПеред = "")` — Устанавливает настройку переопределения обработчика события Перед...
- `После(ВыполнитьПосле = "")` — Устанавливает настройку переопределения обработчика события После...
- `Представление(Представление, ИспользуяИмя = Ложь)` — Устанавливает представление объекта, может использоваться как для теста, так и для набора.
- `ЗависитОт()` — Позволяет выполнить настройку зависимостей теста, тестового набора или модуля.
- `Настроить(_)` — Используется для настройки текущего регистрируемого объекта
- `СвойствоОтчета(КлючСвойства, ЗначениеСвойства)` — Устанавливает свойство отчета для текущего теста, набора тестов или модуля.
- `СвойстваОтчета(СтруктураСвойств)` — Устанавливает набор свойств отчета для текущего теста, набора тестов или модуля.
- `Вызов(_)` — Устарела. Используется для вызова произвольной функции внутри текучего интерфейса

## МокитоОбучение
- `Обучение(Объект, СброситьСтарыеНастройки = Истина)` — Начинает обучение мокито для регистрации правил подмены вызовов методов.
- `Наблюдать(ИмяМетода, ПараметрыВызова = Неопределено)` — Включает наблюдение за вызовами метода, при необходимости можно настроить фильтр по параметрам вызова.
- `Когда(ИмяМетода, ПараметрыВызова = Неопределено)` — Задает условие "подмены" поведения метода.
- `Вернуть(Результат)` — Указывает, что при соблюдении условий (см. Когда) метод должен вернуть указанный результат.
- `ВыброситьИсключение(ТекстИсключения)` — Указывает, что при соблюдении условий (см. Когда) метод должен выбросить исключение.
- `Пропустить()` — Указывает, что при соблюдении условий (см. Когда) метод не должен выполняться, его вызов пропускается.
- `ВыполнитьМетод()` — Указывает, что при соблюдении условий (см. Когда) метод должен выполняться.
- `Прогон()` — Переводит мокито в режим прогона тестов.
