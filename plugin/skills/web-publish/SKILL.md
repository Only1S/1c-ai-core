# /web-publish — Публикация 1С через Apache

Генерирует `default.vrd`, настраивает `httpd.conf` и запускает Apache HTTP Server для веб-доступа к информационной базе. При необходимости скачивает portable Apache. Идемпотентный — повторный вызов обновляет конфигурацию.

## Usage

```
/web-publish [database]
/web-publish dev
/web-publish dev --manual
/web-publish dev --port 9090
```

## Параметры подключения

Прочитай `.v8-project.json` из корня проекта и разреши базу:
1. Если пользователь указал параметры подключения (путь, сервер) — используй их, **только если такая база есть в `.v8-project.json`** (правка ядра: незарегистрированная база считается боевой, `docs/safety/secrets-and-production-database.md`; барьер `guard-destructive` такой вызов отклонит)
2. Если указал базу по имени — ищи по id / alias / name в `.v8-project.json`
3. Если не указал — сопоставь текущую ветку Git с `databases[].branches`
4. Если ветка не совпала — используй `default`

**ОБЯЗАТЕЛЬНО передавай все найденные параметры:**
- **`-V8Path`** — `v8path` найденной записи базы, иначе корневой `v8path`. Не задан ни там, ни там — спроси пользователя, какую платформу брать, и впиши её в `v8path` в `.v8-project.json` (правка ядра: без `-V8Path` скрипт взял бы новейшую установленную платформу — она может быть другой линейки, например 8.5, и сконвертировать базу; барьер `guard-destructive` такой запуск отклоняет)
- **`-UserName`** — из поля `user` найденной записи базы (если есть)
- **`-Password`** — из поля `password` найденной записи базы (если есть). Там ссылка `${ИМЯ}`: передавай её как есть, в одинарных кавычках, скрипт возьмёт значение из окружения; переменной нет — отказ кодом 2 с её именем (правка ядра)
- **`-ApachePath`** — из `webPath` в `.v8-project.json` (если есть)

Если файла `.v8-project.json` нет — предложи `/db-list add`.

## Команда

```powershell
python "${CLAUDE_SKILL_DIR}/scripts/web-publish.py" <параметры>
```

Нужен модуль Python `psutil`: без него скрипт сразу завершится с кодом 1 и подсказкой `python -m pip install --user psutil` (правка ядра).

### Параметры скрипта

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `-V8Path <путь>` | нет | Каталог bin платформы (для wsap24.dll) |
| `-InfoBasePath <путь>` | * | Файловая база |
| `-InfoBaseServer <сервер>` | * | Сервер 1С (для серверной базы) |
| `-InfoBaseRef <имя>` | * | Имя базы на сервере |
| `-UserName <имя>` | нет | Имя пользователя |
| `-Password <пароль>` | нет | Пароль или ссылка `${ИМЯ}` — значение ложится в `default.vrd` открытым текстом |
| `-AppName <имя>` | нет | Имя публикации (по умолчанию из имени каталога базы) |
| `-ApachePath <путь>` | нет | Корень Apache (по умолчанию `tools/apache24` в папке проекта) |
| `-Port <порт>` | нет | Порт (по умолчанию `8081`) |
| `-Manual` | нет | Не скачивать — только проверить и дать инструкцию |
| `-Download` | нет | Разрешить скачать portable Apache, если его нет. Без ключа скрипт только даёт инструкцию |
| `-Sha256 <хэш>` | нет | Ожидаемый SHA256 архива Apache (с apachelounge.com): не совпал — архив удаляется, Apache не ставится, код 1; без ключа хэш скачанного архива печатается для сверки вручную (правка ядра) |

> `*` — нужен либо `-InfoBasePath`, либо пара `-InfoBaseServer` + `-InfoBaseRef`

## Безопасность (правки этого ядра)

- **Только тестовая база.** Публикуется база, зарегистрированная в `.v8-project.json`; незарегистрированную защита считает боевой и не даёт её публиковать.
- **Только этот компьютер.** По умолчанию Apache слушает `127.0.0.1`. Открыть доступ из сети — решение владельца: он сам вписывает адрес в строку `Listen` блока `# --- 1C: global ---` в `httpd.conf`; при повторной публикации вписанные адреса сохраняются.
- **Скачивание — с согласия.** Если Apache нет, сначала спросить владельца окном вариантов, затем повторить с `-Download`; хэш архива с apachelounge.com передать в `-Sha256` (правка ядра).
- **Пароль открытым текстом.** `-Password` записывается в `default.vrd` как есть — так устроена публикация 1С. Для рабочих данных публиковать без пароля и входить под своим пользователем.

## Несколько пользователей одной базы

Повторный вызов с тем же AppName **заменяет** публикацию (идемпотентность). Это используется для:
- смены пользователя: «опубликуй под Ивановым» → тот же AppName, новый `-UserName`
- перезапуска после `/web-stop`: тот же вызов поднимает Apache обратно

Если пользователь просит **параллельную** публикацию под другим пользователем (для тестирования разных наборов прав), добавь суффикс к AppName:
- база `bpdemo`, пользователь `Иванов` → `-AppName bpdemo-ivanov`
- база `bpdemo`, пользователь `Admin` → `-AppName bpdemo-admin` (или просто `bpdemo`)

Ключевые слова: «ещё одну публикацию», «дополнительно», «параллельно», «под другим пользователем не убирая текущую».

## После выполнения

1. Сообщи URL-ы:
   - Веб-клиент: `http://localhost:{Port}/{AppName}`
   - OData: `http://localhost:{Port}/{AppName}/odata/standard.odata`
   - HTTP-сервисы: `http://localhost:{Port}/{AppName}/hs/<RootUrl>/...`
   - Web-сервисы: `http://localhost:{Port}/{AppName}/ws/<Имя>?wsdl`
2. Предложи открыть в браузере
3. Если нужно протестировать сервис — помоги составить запрос
4. Незарегистрированную базу скилл не публикует (барьер `guard-destructive` вызов отклонит): сперва пользователь регистрирует её как тестовую — `/db-list add` (правка ядра)

Сервисы расширений публикуются наравне с сервисами конфигурации. Если сервис расширения всё же
отдаёт 404 (HTTP) или 500 «Сервис не найден» (SOAP) — расширение не применено к базе данных:
`/db-update -Extension <имя>`.

## Примеры

```powershell
# Файловая база
python "${CLAUDE_SKILL_DIR}/scripts/web-publish.py" -InfoBasePath "C:\Bases\MyDB" -UserName "Admin"

# С явным именем публикации и портом
python "${CLAUDE_SKILL_DIR}/scripts/web-publish.py" -InfoBasePath "C:\Bases\MyDB" -AppName "mydb" -Port 9090

# Серверная база
python "${CLAUDE_SKILL_DIR}/scripts/web-publish.py" -InfoBaseServer "srv01" -InfoBaseRef "MyDB" -UserName "Admin" -Password "secret"

# Ручной режим (только инструкция)
python "${CLAUDE_SKILL_DIR}/scripts/web-publish.py" -InfoBasePath "C:\Bases\MyDB" -Manual
```
