## 1. Что это за книги

- **Книга 4 «Руководство пользователя»** — 15 глав и 6 приложений. Описывает интерфейс «Формы в закладках» и в гл. 15 — режим обычного приложения (толстый клиент старых конфигураций). Здесь же установка клиента, запуск, режим низкой скорости, приложения: язык выражений системы компоновки данных (СКД), редакторы текстовых, табличных, HTML-документов, графической и географической схем.
- **Книга 5 «Интерфейс „Такси“»** — 12 глав. Тот же материал для интерфейса «Такси» (основной у современных типовых конфигураций), плюс главы, которых нет в книге 4: **гл. 7 «Система взаимодействия»** и **гл. 11 «Работа с веб-клиентом»** (поддерживаемые браузеры, их настройка, прогрессивное веб-приложение).
- Внешний вид меняется в «Сервис → Параметры» (флажки «Такси (рекомендуется)» / «Формы в закладках»), действует после перезапуска; доступность варианта зависит от конфигурации.

## 2. Установка клиента (книга 4, гл. 2)

**Windows.** Программа установки — `setup.exe` из каталога дистрибутива (с диска — `autorun.exe`, режимы «Быстрая установка и запуск» и «Выборочная установка»). Компоненты, доступные для выбора:

| Компонент | Что ставит |
|---|---|
| 1С:Предприятие | всё клиентское, включая толстый и тонкий клиент |
| 1С:Предприятие — тонкий клиент | тонкий клиент только для клиент-серверных баз |
| 1С:Предприятие — тонкий клиент, файловый вариант | тонкий клиент плюс компоненты для файловых баз |

- Часть каталогов создаётся в фиксированных местах независимо от выбранной папки; подробности — «Руководство администратора», гл. 2 (конспект `adm-gl02-ustanovka-p1.md`).
- Каждая установленная версия — отдельная строка «1С:Предприятие 8 (A.B.C.D)» в «Программах и компонентах».
- Тонкий клиент из самораспаковывающегося архива `1CEClientSetup.exe`, скачанного из интернета, перед запуском проверить по цифровой подписи (издатель — «1С» или доверенный провайдер).
- В конце мастер предлагает поставить драйвер ключа защиты (HASP Device Driver) — только при установке «для компьютера». Ставить, если к этому компьютеру будет подключён USB-ключ (основной поставки, клиентский или серверный). Ставить драйвер **до** подключения ключа. При установке драйвера ставится и его веб-интерфейс; документация рекомендует оставить флажок «Отключить неиспользуемые 1С:Предприятием возможности аппаратных ключей защиты» (подробности — методичка ИТС 5936, разбор — `kb/1c-windows/05-…`).

**macOS.** Образы `clientosx_A_B_C_D.dmg` (толстый и тонкий клиент) и `thin.clientosx_A_B_C_D.dmg` (только тонкий), внутри пакеты `1cv8-client-A.B.C.D.pkg` / `1cv8-thin-client-A.B.C.D.pkg`; нужны имя и пароль администратора macOS. Выбора компонентов нет.

**Linux.** Программы установки `setup-<name>-A.B.C.D-<arch>.run`: `full` — все компоненты, `thin` — тонкий клиент и компоненты доступа к кластеру (в тексте ещё упомянут учебный вариант, в источнике с опечаткой `traning`); `arch` — `i386` или `x86_64`. Файлу нужно право на выполнение (`chmod`). Установщик может вывести список недостающих пакетов — их ставят пакетным менеджером от `root`. Подробно для Ubuntu — `kb/1c/02`, `kb/1c/09`.

**Установка конфигурации (шаблона).** Отдельная программа: `setup.exe` в Windows, `setup` в Linux → указать каталог шаблонов → «Далее» → «Готово».

**Активация лицензии.** Поставка содержит либо аппаратный ключ, либо пин-код программной лицензии. Программная лицензия привязана к параметрам компьютера: имени и версии ОС, серийному номеру и дате установки ОС, имени материнской платы, числу процессоров и др. При их изменении может понадобиться новая активация с новым пин-кодом. Полный перечень ключевых параметров — «Руководство администратора», гл. 10 (конспект `adm-gl10-zashchita-licenzii-p1.md`, разбор — `kb/1c/04`).

**Особенности Linux (разд. 2.7).**
- Нужны шрифты Microsoft Core Fonts (в Ubuntu — пакет `ttf-mscorefonts-installer`; иначе — вручную в `$HOME/.fonts` пользователя, под которым запускается 1С).
- Внешние библиотеки и их назначение:

| Библиотека | Имя | Минимальная версия | Для чего |
|---|---|---|---|
| ImageMagick | `libMagickWand` / `libWand` / `libMagickWand-6.Q16` | 6.2.8; 6.3.2 для географической схемы; 6.6.9 для SVG | сервер в управляемом режиме, диаграммы |
| Fontconfig | `libfontconfig` | 2.3.0 | сервер в управляемом режиме, `ТабличныйДокумент` и диаграммы на сервере, PDF |
| FreeType | `libfreetype` | 2.1.9 | диаграммы, PDF |
| Libgsf | `libgsf-1` | 1.10.1 | импорт и экспорт XLS |
| Glib | `libglib-2.0` | 2.12.4 | внешние источники данных |
| unixODBC | `libodbc` | 2.2.11 | внешние источники данных |
| Kerberos | `libkrb5`, `libgssapi_krb5` | 1.4.2 | аутентификация средствами ОС |

- Для удалённого подключения к рабочему столу Linux документация называет TightVNC.

**Автоудаление неиспользуемых версий (разд. 2.8).** Включается в настройках диалога запуска. Пользователь получает оповещение и может запустить фоновое удаление (нужны права в ОС), отложить или отказаться. После отказа («Не предлагать удалять») включить обратно можно только в настройках автоудаления.

## 3. Запуск и вход (книга 4, гл. 3)

- Исполняемые файлы: тонкий клиент — `1cv8c.exe` (Linux: `1cv8c`), толстый — `1cv8.exe` (`1cv8`). В меню «Пуск» 64-разрядная версия — отдельная группа «1C Предприятие 8 (x86-64)».
- **Если установлены и 32-, и 64-разрядные версии, кнопка «1С:Предприятие» в окне запуска запускает 32-разрядную.** Управляется параметром базы «Разрядность».
- Окно входа может предлагать: «Запомнить» (сохранение данных аутентификации), «Забыли пароль?» (страница восстановления или код на почту), вход через QR-код (подтверждение в мобильном приложении: «Настройки и сервис → Войти на другом устройстве»), вход через внешний сервис (пример — Госуслуги), вход по коду из письма. Набор зависит от настроек базы.
- **Параметры базы в списке** (диалог «Добавить»/«Изменить»):
  - вариант аутентификации — «Выбирать автоматически» (сначала средствами ОС, при неудаче — имя и пароль) или «Запрашивать имя и пароль»;
  - скорость соединения — «Обычная», «Низкая», «Выбирать при запуске»;
  - дополнительные параметры запуска — ключи командной строки (справочник — `adm-pr07-parametry-zapuska-1cv8-p1…p3.md`);
  - основной режим запуска — авто, тонкий клиент, веб-клиент, толстый клиент;
  - версия платформы для этой базы;
  - разрядность (только на 64-разрядной Windows) — «32 (x86)», «Приоритет 32 (x86)», «64 (x86_64)», «Приоритет 64 (x86_64)». «Приоритет» — сначала ищется самая новая версия, а разрядность выбирается среди имеющихся у неё.
- Подробно о списке баз (`ibases.v8i`, общие списки, `1cestart.cfg`) — «Руководство администратора», гл. 5 (`adm-gl05-spisok-infobaz.md`); для Windows — `kb/1c-windows/04-…`.

## 4. Режим низкой скорости соединения (книга 4, гл. 14; книга 5, разд. 11.2.4.1)

- Задаётся в параметрах базы или флажком «Низкая скорость соединения» в окне запуска. Для веб-клиента — «Сервис и настройки → Настройки → Параметры → Устанавливать режим низкой скорости соединения при запуске» или параметр адресной строки `О=Low`.
- Как работает: меньше обращений к серверу, не передаётся второстепенное. Например, нет картинок разделов, рабочий стол открывается только по ссылке «Показать рабочий стол». Выбор в полях ввода по возможности берёт уже полученные данные, поэтому новое значение может не появиться до повторного выбора или F5. Выпадающий список при вводе сам не раскрывается — нужна «Стрелка вниз».
- **Блокировки:** оповещение сервера о закрытии формы, которая держала блокировку данных, уходит через 20 секунд или вместе со следующим запросом. Поэтому «объект заблокирован» у соседей держится дольше.

## 5. Системные параметры клиента (книга 4, разд. 11.3; книга 5, разд. 9.3; обычное приложение — разд. 15.3.1.4)

Вызов: «Сервис и настройки → Настройки → Параметры» (в «Формах в закладках» — «Сервис → Параметры»).

| Параметр | Назначение |
|---|---|
| Внешний вид | «Такси» / «Формы в закладках»; действует после перезапуска |
| Отладка в текущем сеансе / Сервер отладки | разрешить отладку этого сеанса по выбранному протоколу; адрес и порт сервера отладки |
| Отладка при перезапуске / Сервер отладки при перезапуске | то же для следующих запусков |
| Отображать показатели производительности | окно со счётчиками вызовов сервера (по умолчанию слева внизу) |
| Имитировать задержку при вызовах сервера | проверка работы конфигурации на медленном канале |
| «Все функции» (Формы в закладках) / «Режим технического специалиста» (Такси) | добавляет в меню список всех объектов конфигурации, в том числе отсутствующих в интерфейсе; доступно при наличии права. В «Такси» также добавляет пункт «Информация для технического специалиста» (полный путь объекта в конфигурации) в меню форм и панели открытых, а при включённой отладке — «Открыть в Конфигураторе» |

- В обычном приложении (книга 4, разд. 15.3.1.4) флажок «Отладка в текущем сеансе разрешена» после применения снять нельзя; для следующего запуска — «Устанавливать режим разрешения отладки при запуске».
- «Функции для технического специалиста» (книга 5, разд. 8.6): группа «Стандартные» содержит служебные функции (активные пользователи, журнал регистрации и др.). Объекты без права просмотра в список не попадают. Поиск — по началу слова, Ctrl+F, отмена — Ctrl+Q.

## 6. Что пользователь может прислать в поддержку

- **Окно «О программе»** (книга 4, разд. 12.2): версия платформы; конфигурация с версией, расширениями и результатом проверки лицензионного использования; имя базы из списка; режим («Файловый»/«Клиент-Сервер», режим сжатия, признак низкой скорости); каталог базы и региональные установки; клиентское приложение (толстый, тонкий, веб), скорость и сжатие; пользователь; локализация базы и сеанса; текущие клиентская и серверная лицензии и все лицензии, работавшие с базой; ссылки «Лицензии используемых компонентов» и **«Информация для технической поддержки»** (сведения о программе и журнал ошибок, копируется Ctrl+C).
- **Отчёт об ошибке** (книга 4, разд. 10.13; книга 5, разд. 8.17): в окне ошибки ссылка «Сформировать отчёт об ошибке». В отчёт можно включить подробный текст ошибки, снимок экрана, имя пользователя, обобщённые сведения об ОС клиента, **дамп аварийного завершения** (если он сформирован) и любые файлы. Конфигурация может формировать отчёт автоматически. Серверная сторона отчётов об ошибках — `dev-gl31-otladka-oshibki-testirovanie.md`.
- **Журнал регистрации в обычном приложении** (книга 4, разд. 15.5): открыть журнал → «Файл → Сохранить как» → формат журнала `*.lgf` или XML.

## 7. Прочее, что влияет на администрирование

- **Работа нескольких пользователей** (книга 4, разд. 7.6): объект, который уже редактирует другой пользователь, не даст начать правку. В предупреждении — номер сеанса и имя компьютера держателя блокировки. Блокировка снимается через минуту после сохранения изменений; затем объект нужно перечитать. Номер сеанса из сообщения ищется в консоли кластера или через `rac session list` (`kb/1c/03`).
- **Временная блокировка** (книга 4, разд. 10.12; книга 5, разд. 8.15): только толстый клиент и только для пользователя с паролем. Окно сворачивается, вернуться можно только по паролю входа.
- **Пароль пользователя в обычном приложении** (книга 4, разд. 15.4): «Сервис → Параметры пользователя». По тексту книги — без пробелов и специальных символов, не длиннее 255 символов. Политики паролей и их проверку из конфигурации см. `dev-gl34-prochie-mehanizmy.md`.
- **История данных** (книга 5, разд. 8.5): команда «История изменений» на форме объекта, если разработчик включил историю для этого вида объектов. Есть сравнение версий, отбор по автору, периоду и полям. Команды «Открыть версию» и «Перейти на версию» позволяют восстановить объект — нужно отдельное право. Для проведённого документа, который в нужной версии не был проведён, сначала отменяется проведение. Устройство механизма — `dev-gl21-gl25-vremennoe-hranilishche-istoriya-dannyh.md`.
- **«1С:Аналитика»** (книга 5, разд. 8.12): работает, только если приложение опубликовано на веб-сервере вместе с системой аналитики и подключение идёт по HTTP. У пользователя должно быть право на запуск клиента аналитики. Открывается во вкладке браузера; документация на механизм отдельная.
- **Windows 7+ и Linux Unity** (разд. 10.14 / 8.18): в список переходов ярлыка 1С на панели задач попадают недавно открытые базы, их можно закрепить.
- **Сенсорный экран** — тонкий клиент под Windows; **экранный доступ** — рекомендована NVDA (Windows 7 и новее).

## 8. Веб-клиент (книга 5, гл. 11)

**Поддерживаемые браузеры** (по тексту 8.3.27): Google Chrome 49+ (Windows, macOS, Linux); Mozilla Firefox 52+; Internet Explorer 11; Safari 4.0.5+ (Mac OS 10.5+); Chrome для Android; Safari Mobile (iPhone/iPad); на основе Chromium — chromium-gost 49+, Microsoft Edge 19+, Яндекс.Браузер 22+. Веб-клиент можно встроить в сторонний сайт. Internet Explorer 11 сам Microsoft снял с поддержки в 2022 году — на рабочих местах его не использовать.

**Запуск и лицензии.** Адрес базы в браузере; к адресу автоматически добавляется `/aa_BB` (язык и страна). В одном браузере можно открыть несколько сеансов одной базы — каждый в своей вкладке, **и каждый расходует клиентскую лицензию**.

**Что требует HTTPS** (это причина публиковать базы по HTTPS — `kb/1c/05`, `kb/1c-windows/03-…`):
- демонстрация экрана в системе взаимодействия. Chrome 72+ — нужно расширение «1С:Предприятие» с правом «Снимок содержания экрана»; Firefox — только HTTPS;
- диалог выбора камеры и микрофона в Chrome и Firefox — HTTPS или публикация на `localhost`;
- видеозвонки в Chrome;
- распознавание речи — не работает по HTTP (кроме `localhost`), а также в Firefox, Safari, IE и Chromium до 65;
- прогрессивное веб-приложение (PWA): HTTPS плюс Яндекс.Браузер 22+, Edge 73+ или Chrome 73+. Команда «Отображать как отдельное приложение», ярлык попадает в «Пуск» и на рабочий стол (Windows) или в Dock.

**Работа с файлами, буфером, криптографией, внешними компонентами.** Без расширения браузера операции с файлами — только интерактивные. Расширение «для работы с 1С:Предприятием» для Chrome и Firefox (Firefox — также из каталога дополнений Mozilla) даёт доступ к диску и буферу обмена. Разрешения хранятся по сайтам, меняются в параметрах расширения. Страница параметров в Chrome: `chrome-extension://pbhelknnhilelbnhfpcjlcabhmfangik/options.html`. Для Internet Explorer — компонент ActiveX «Расширение работы с файлами» (x86 или x64; установку предусматривает прикладное решение, при нехватке прав ставит администратор).

**Аутентификация средствами ОС в Firefox** (разд. 11.4.2; `about:config`):
- NTLM — сервер в `network.automatic-ntlm-auth.trusted-uris`, иначе браузер спросит логин и пароль;
- Kerberos — сервер в `network.negotiate-auth.trusted-uris`. Для файловой базы этого достаточно; **для клиент-серверной DNS-имя веб-сервера нужно добавить ещё в `network.negotiate-auth.delegation-uris`** (делегирование билета дальше, на сервер 1С). Со стороны домена — `kb/1c-windows/04-…`.

**Ограничения:**
- Safari — нет внешних компонент и расширения криптографии, нет автоматической аутентификации ОС;
- масштаб браузера должен быть 100 %, нестандартный dpi не поддерживается;
- печать табличного документа по умолчанию идёт в PDF, HTML — в параметрах; в Chrome иногда нужен Adobe Reader;
- Ctrl+Break не прерывает выполнение;
- главное меню вызывается F10, а не Alt;
- на iPad — без печати, перетаскивания, расширений и внешних компонент.

**Настройки браузеров** (разд. 11.3–11.7): разрешить JavaScript и cookies для адресов баз (в том числе сторонние cookies — в IE). Рекомендуется спрашивать место сохранения файлов. Для IE с внешними компонентами — зона «Местная интрасеть» или «Надёжные узлы» и разрешение подписанных ActiveX.

## 9. Система взаимодействия глазами пользователя (книга 5, гл. 7)

- **Архитектура (разд. 7.1):** клиентская часть встроена в платформу; серверная — отдельный продукт «1С:Предприятие — Сервер взаимодействия», в интернете или в локальной сети. Обмен — по WebSocket (открытый или защищённый). Сервер хранит всю переписку. Отдельной регистрации нет — пользователи берутся из информационной базы. Развёртывание своего сервера — `kb/guides/04-1c-server-vzaimodejstviya.md`, со стороны базы — `dev-gl29-sistema-vzaimodejstviya.md`.
- **«1С:Диалог» (разд. 7.2):** демонстрационный экземпляр фирмы «1С», адрес `wss://1cdialog.com:443`, нужен интернет. Передача файлов и сроки хранения — по условиям на `1cdialog.com/ru/pricing/`. Переписка хранится у «1С», поэтому для рабочих данных — свой сервер.
- **Внешние пользователи (разд. 7.5):** приглашение по e-mail со ссылкой на сайт `dialog.1c.com` или на сайт своего сервера взаимодействия. Внешнему участнику доступны только неконтекстные обсуждения. Он видит только тех, с кем у него общие обсуждения, и не может менять состав участников. Сайт работает на русском и английском. В iOS нет PWA и push-оповещений.
- **Видеозвонки (разд. 7.6):** их должен разрешать сервер взаимодействия, у участников нужен микрофон.
  - Клиенты: тонкий и толстый на Windows 7+ и macOS, на Linux — **только тонкий**.
  - Через RDP камера и микрофон должны пробрасываться с компьютера, с которого идёт подключение.
  - Веб-клиент: Chrome 64+ (кроме iOS), Edge 64+ на Chromium, Firefox 52+ (кроме iOS), Safari 13+; в Chrome — только по HTTPS.
  - Звонок можно перевести на другое устройство того же пользователя.
- **«1С:Предприятие — оповещения и запуск» (разд. 7.7):** отдельная программа для оповещений при закрытом клиенте. Ставится ссылкой «установить» в настройках обсуждений и по умолчанию ставит заодно расширения для Chrome, Firefox и Internet Explorer. Ярлык: в Windows — «1С Предприятие 8 → Дополнительно», в Linux — категория Office:Finance. Из её меню открывается окно запуска, видны непрочитанные по приложениям, оповещения можно временно выключать.
- **Недоступность сервера (разд. 7.8):** окно «соединение с сервером системы взаимодействия отсутствует», на закладке «Обсуждения» — красный треугольник. Проверять доступность сервера взаимодействия и WebSocket через прокси или балансировщик.

## Что важно администратору — коротко

1. При двух разрядностях клиента кнопка «1С:Предприятие» запускает 32-разрядный. Нужную разрядность задавать в параметре базы «Разрядность».
2. Каждая вкладка веб-клиента с базой — отдельный сеанс и отдельная клиентская лицензия.
3. Для видеозвонков, демонстрации экрана, выбора устройств, распознавания речи и PWA нужна публикация по HTTPS.
4. Сквозная аутентификация Kerberos в Firefox для клиент-серверной базы требует `network.negotiate-auth.delegation-uris`, а не только `trusted-uris`.
5. Видеозвонки в Linux — только из тонкого клиента; через RDP — с пробросом камеры и микрофона.
6. «Информация для технической поддержки» в окне «О программе» и «Сформировать отчёт об ошибке» (с дампом) — первое, что просить у пользователя при разборе ошибки.
7. При изменении параметров компьютера программная лицензия может потребовать повторной активации новым пин-кодом.
8. Драйвер HASP ставить до подключения ключа, его веб-интерфейс отключать.
