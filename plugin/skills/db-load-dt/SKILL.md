# /db-load-dt — Загрузка информационной базы из DT-файла

Восстанавливает информационную базу целиком (конфигурация **+ данные**) из DT-файла.

## ⚠️ Необратимая операция

Загрузка `.dt` **полностью перезаписывает базу** — и конфигурацию, и все данные. Текущее содержимое базы теряется безвозвратно; откат возможен **только из бэкапа, сделанного заранее**. Цикл ниже обязателен, шаги не пропускаются и не переставляются.

1. **Бэкап — точка отката.** До любого изменения: `/db-dump-dt` текущего состояния базы (конфигурация + данные). Восстанавливаться будет нечем, если этого снимка нет → без бэкапа операция не начинается.
2. **Проверка целевой базы.** База разрешается по `.v8-project.json` (id / alias / name, иначе ветка Git → `default`) и **называется пользователю явно** (путь файловой базы либо сервер + имя). **Целевая база обязана быть зарегистрирована в `.v8-project.json`; незарегистрированная считается боевой (`docs/safety/secrets-and-production-database.md`) — не трогать.**
3. **Сухой прогон.** Показать пользователю: какая база будет затёрта, каким DT-файлом, где лежит бэкап из шага 1. Если цель — **создать новую** базу из `.dt`, это `/db-create`, а не загрузка в существующую.
4. **Явное подтверждение пользователя** — окном вариантов (AskUserQuestion), «применить / отменить»: вся база (данные + конфигурация) будет перезаписана. Общее «продолжай» из контекста подтверждением **не** считается (`docs/process/ask-before-changing.md`, `docs/process/questions-as-options.md`).
5. **Применение** — только после подтверждения. `/db-update` после загрузки **не нужен** — конфигурация БД синхронна внутри снимка.
6. **Проверка** — полный сет чекеров после правки (`docs/tools/full-checker-set-before-done.md`): база открывается, конфигурация и данные соответствуют ожидаемому снимку.
7. **Откат** — если результат не тот: `/db-load-dt <бэкап.dt>` из шага 1.

## Когда НЕ использовать

- Нужно создать **новую** базу из `.dt` → используй `/db-create` (из DT-шаблона), а не загрузку
  в существующую.
- Нужно обновить только конфигурацию (без данных) → `/db-load-cf` или `/db-load-xml`.

## Usage

```
/db-load-dt <input.dt> [database]
/db-load-dt backup.dt dev
```

## Параметры подключения

Прочитай `.v8-project.json` из корня проекта. Возьми `v8path` (путь к платформе) и разреши базу:
1. Если пользователь указал параметры подключения (путь, сервер) — используй их, **только если такая база есть в `.v8-project.json`** (правка ядра: незарегистрированная база считается боевой, `docs/safety/secrets-and-production-database.md`; барьер `guard-destructive` такой вызов отклонит)
2. Если указал базу по имени — ищи по id / alias / name в `.v8-project.json`
3. Если не указал — сопоставь текущую ветку Git с `databases[].branches`
4. Если ветка не совпала — используй `default`
Если `v8path` не задан — спроси пользователя, какую платформу брать, и впиши её в `v8path` в `.v8-project.json` (правка ядра: без `-V8Path` скрипт взял бы новейшую установленную платформу — она может быть другой линейки, например 8.5, и сконвертировать базу; барьер `guard-destructive` такой запуск отклоняет).
Если файла нет — предложи `/db-list add`.
Если база не зарегистрирована — операция **не выполняется**: сперва пользователь решает, регистрировать ли её как тестовую (`/db-list add`) (правка ядра).

## Команда

```powershell
python "${CLAUDE_SKILL_DIR}/scripts/db-load-dt.py" <параметры>
```

### Параметры скрипта

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `-V8Path <путь>` | нет | Каталог bin платформы, или полный путь к `1cv8.exe` / `ibcmd.exe` |
| `-InfoBasePath <путь>` | * | Файловая база |
| `-InfoBaseServer <сервер>` | * | Сервер 1С (для серверной базы) |
| `-InfoBaseRef <имя>` | * | Имя базы на сервере |
| `-UserName <имя>` | нет | Имя пользователя |
| `-Password <пароль>` | нет | Пароль |
| `-InputFile <путь>` | да | Путь к DT-файлу |
| `-JobsCount <N>` | нет | Число фоновых заданий загрузки (0 = по числу процессоров) |
| `-UnlockCode <код>` | нет | Код разблокировки (`/UC`), если заблокировано начало сеансов |
| `-AdditionalV8Arguments <список>` | нет | Доп. аргументы запуска `1cv8.exe` через запятую, напр. `/UseHwLicenses+` |
| `-AdditionalIbcmdArguments <список>` | нет | Доп. аргументы `ibcmd` через запятую, в форме `--ключ=значение` |

> `*` — нужен либо `-InfoBasePath`, либо пара `-InfoBaseServer` + `-InfoBaseRef`

## После выполнения

Если база занята (активные сеансы), загрузка не выполнится — для серверной базы можно
передать `-UnlockCode`; иначе освободи базу и повтори.

## Примеры

```powershell
# Файловая база
python "${CLAUDE_SKILL_DIR}/scripts/db-load-dt.py" -InfoBasePath "C:\Bases\MyDB" -UserName "Admin" -InputFile "C:\backup\base.dt"

# Серверная база с ускорением загрузки
python "${CLAUDE_SKILL_DIR}/scripts/db-load-dt.py" -InfoBaseServer "srv01" -InfoBaseRef "MyApp_Test" -UserName "Admin" -Password "secret" -InputFile "base.dt" -JobsCount 4
```

## Связанные навыки

- `/db-dump-dt` — выгрузка ИБ в DT (обратная операция, точка отката перед загрузкой)
- `/db-create` — создать новую базу (в т.ч. из DT-шаблона)
