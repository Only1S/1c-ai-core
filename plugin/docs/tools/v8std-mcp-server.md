Справочник стандартов разработки 1С:Предприятие — https://v8std.ru/ (317 стандартов, 809 диагностик по данным сайта на момент записи — повторно не пересчитывалось; диагностики BSL Language Server / АПК / EDT, раздел паттернов SOLID/GOF/GRASP).

Доступ для ИИ — официальный MCP-сервер: `https://ai.v8std.ru/mcp` (HTTP/SSE). Прописан в проектном `D:\dev_core\.mcp.json` как сервер `v8std`. Активируется после перезапуска Claude Code и подтверждения MCP.

Версия сервера на дату сверки — **serverInfo.version = 1.27.0**, protocolVersion `2025-06-18` (зонд 16.10.2026; снимается POST-хендшейком `initialize` через curl на тот же URL — у дока должен быть предмет сверки, а не только адрес).

Инструменты MCP:
- `v8std_search` — поиск по стандартам (`std437`) и кодам диагностик (`bslls:UsingModalWindows`)
- `v8std_get_page` — полный текст страницы стандарта/диагностики
- `v8std_get_related` — связанные материалы
- `v8std_explain_diagnostics` — объяснение списка диагностик
- `v8std_explain_snippet` — разбор одной процедуры BSL или фрагмента запроса по стандартам (появился у сервера позже; в списке инструментов сессии 18.09.2026 — пятый). Текст процедуры уходит на `ai.v8std.ru` как есть, вместе с ключами и паролями, если они в коде: запрет снят решением владельца 31.10.2026 (ADR-0012). Карту стандартов он не заменяет — [[code-situation-standards-map]]

⚠️ Публичный сервис видит текст запросов — НЕ отправлять закрытый код или коммерческие данные, только имена стандартов и общие вопросы.

Используется вместе со скиллом 1С БСП в `D:\dev_core\.claude\skills\bsp` (см. [[bsp-skill-source]]).
