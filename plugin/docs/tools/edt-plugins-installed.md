# EDT Plugin Pack (Jimmo910) — состав и что стоит в EDT

> **Состояние на 30.10.2026 (сверка `bundles.info`):** на стенде теперь **EDT 2026.2.2** (`D:\EDT\installations\1C_EDT 2026.2`, `eclipse.buildId=2026.2.2.21`, папка создана 29.10.2026); папки прежней установки 2026.1 нет, рядом — `backup-2026.2-before-plugins-20261030` (копия без плагинов от 29.10). В `bundles.info` от 30.10.2026 11:32 стоят **EDT MCP Server 2.22.1** (`com.ditrix.edt.mcp.server,2.22.1,…,4,false`) и **Extension Tweaks 1.1.29** (`ru.xelgo.edt.contextlinks.ui`, `1.1.29.v202610291153`) с новым бандлом `ru.xelgo.edt.opensources.ui` 1.0.0. **Остального нет:** Disable Editing, Test Runner, Configuration Repository, AnyEdit, IndentGuide, Fast Button, Comfort, а также EDT-Favorites и ExtDumper в `bundles.info` не найдены. Таблицы ниже описывают **прежнюю установку EDT 2026.1.3** (сверка 16.10.2026; замер 29.10.2026 по её `bundles.info` от 20.10 видел EDT MCP Server 2.21.1). Поставить остальное в 2026.2 — решение владельца среды. `edt-mcp` не отвечает — сперва проверить, запущена ли EDT с проектом и слушает ли порт, а не ставить плагин заново. Живым ответом сервер 2.22.1 на 30.10.2026 не подтверждён: EDT выключена. В общем пуле p2 (`C:\Program Files\Common Files\.p2\pool\plugins`) лежат jar сервера 2.5.1–2.22.1.

Офлайн-набор плагинов для линий **1C:EDT 2026.1 и 2026.2** (релиз апстрима собирает два архива: `EDT-Plugin-Pack-2026.1-<ver>.zip` и `-2026.2-<ver>.zip`). Линия **2025.2 апстримом снята с поддержки**.

**Версия пака.** Состав ниже сверен с **v2.1.8 (12.10.2026)**; по замеру 29.10.2026 у апстрима уже вышли v2.1.9, v2.2.0 и v2.2.1 (26.10.2026, в составе EDT MCP Server 2.21.1). Сверка: `gh release list -R Jimmo910/edt-plugin-pack`. Номер установленного пака по файлам установки **не определяется** — пак не оставляет своего маркера, видны только версии отдельных бандлов. Поэтому ниже сверяется СОСТАВ, а не номер пака.

**Лицензии состава** (по телу релиза): **EPL-2.0** (Extension Tweaks, Disable Editing, Configuration Repository, AnyEdit, Fast Button), **Apache-2.0** (Test Runner, YAXUnit), **MIT** (IndentGuide, Comfort), а **EDT MCP Server — AGPL-3.0** и учитывается отдельной категорией: это сетевой сервер, и его лицензия строже остальных.

**Два канала установки:**
1. Офлайн-zip: `Help → Install New Software → Add → Archive…` — фиксированные версии, ничего не тянет из сети.
2. Update site по линии EDT: `https://jimmo910.github.io/edt-plugin-pack/2026.1/` (и `/2026.2/`). ⚠️ Он подтянет и `edt-mcp`: после обновления через site сверять версию сервера, иначе наш MCP-порт поедет вместе с паком незаметно.

## Связь с нашим стеком
- **EDT MCP Server = наш `edt-mcp`** ([[installed-tools-and-servers]]): в EDT 2026.1 стоял 2.21.1, в текущей EDT 2026.2 стоит 2.22.1 (`…,4,false` — ленивая активация, сверка `bundles.info` 30.10.2026); живьём не проверялся. Опись инструментов сервера в доках снята на 2.17.1 и живым `tools/list` на поздних версиях **не перепроверялась**; режимы `write_module_source` сверены по jar 2.21.1 ([[edt-mcp-pitfalls]]) — при первом же обращении к серверу сверить состав.
- **EDT Test Runner + YAXUnit → юнит-тесты.** После исправления бага писать YAXUnit-тест и гонять его headless ([[task-recipes]] §12), а не кликать в IDE.
- **AnyEdit** — авто-форматирование BSL; **Disable Editing / Configuration Repository** — поддержка и хранилище (типовые на поддержке, [[config-git-forks-and-merges]]).
- **EDT Comfort checks** и возможный плагин стандартов — дополнительный чекер поверх [[full-checker-set-before-done]]; в наш обязательный сет не входят (их вердикты не машиночитаемы для гейтов).

## Чем сверять (а не помнить)

- Что установлено — `bundles.info` установки EDT: строка `<symbolic-name>,<версия>,<путь>,<уровень>,<автостарт>` значит, что бандл установлен. Уровень 4 — значение по умолчанию, активности он не доказывает. `false` в последнем поле — ленивая активация, а не «выключен»; `true` — явный автостарт (у единиц бандлов). Что бандл работает, подтверждать только живым ответом: для EDT MCP — сервер на порту экземпляра (дефолт 8765) и `tools/list`, скилл smoke.
- Что есть у апстрима: `gh release list -R Jimmo910/edt-plugin-pack`, `gh release view <тег> -R <репо>` по отдельным плагинам.
- Версия самого EDT: каталог установки + `about` IDE.

Установка плагинов — **решение владельца среды**, а не операция ядра: EDT ставится и настраивается вне репозитория проекта.

Инструменты и MCP-стек — [[installed-tools-and-servers]]. Специфику конфигурации проекта документировать отдельным доком в `docs/`.
