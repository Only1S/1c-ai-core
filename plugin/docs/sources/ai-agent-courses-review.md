# Разбор курсов и каталогов про ИИ-агентов

Разобрано 04.11.2026 по просьбе владельца, без помощников: README и уроки прочитаны через `gh api` и WebFetch, наличие у нас — грепом по `docs/`, `plugin/`, `tools/bench/`, скиллам. Итог: почти всё, чему учат курсы, в ядре уже есть в другой форме. Брать стоит два пункта, оба малые.

## Что взять

1. **Замер с разбросом и кейсами из провалов.** Гейт сравнивает долю «с плагином» с допуском 5 п.п. (`tools/lib/quality_report.py`, `TOLERANCE`). При 7 кейсах и одном прогоне один кейс весит 14,3 п.п. (кейс из двух проверок — 7,1 п.п. на проверку): одна случайная осечка модели валит выпуск. Факт 04.11.2026: два замера почти одного содержимого плагина дали «без плагина» 100% и 92,9% (кейс `04-client-server-call` — 100% и 50%). Что сделать: `--runs 2` или 3 в выпуске и правило «дефект живой пробы или наблюдение о качестве ответа → кейс в `tools/bench/evals`». Цена — замер дороже в 2–3 раза (сейчас $1,7–2,2).
2. **Запрет ослаблять тест.** В [[bug-diagnosis-loop]] и в скилл `yaxunit`: красный тест нельзя чинить правкой самого теста (ослабить утверждение, поменять ожидание под факт, пометить пропуск), если владелец не сказал, что неверен тест. Цена — строка правила и признак в ревью.

## Что ещё замечено

- **Citadel** (`SethGammon/Citadel`, MIT; ссылка из каталога 500-AI-Agents) — плагин Claude Code того же рода, что ядро: 48 скиллов, 36 хуков на 29 событиях, маршрутизатор `/do`, кампании и доказательства в `.planning/`, итог проверки `passed`/`failed`/`blocked`/`unknown` («нет доказательства — не успех»), граница «Needs You», команда `/unharness` с планом снятия плагина. Похожее у нас: статусы матрицы готовности и «готов только по зелёному полному сету» ([[full-checker-set-before-done]]). Плана снятия ядра из проекта у нас нет — кандидат на потом, запроса нет. Подробный разбор — [[citadel-review]].
- **GAIA** (итог курса Hugging Face) — общий бенчмарк агентов, для 1С не годится; наш доменный эталон — 1C Code Bench.
- В `ai-engineering-hub` демо держатся на платных облачных сервисах; для ядра, где только свои MCP-серверы, лишнее.
- В каталоге 500-AI-Agents нет сценариев 1С и ERP; польза — только ссылка на Citadel.
