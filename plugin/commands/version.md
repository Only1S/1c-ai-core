Покажи пользователю версию плагина ones-core. Говори простыми словами.

1. **Запуск:** `python "${CLAUDE_PLUGIN_ROOT}/tools/setup/show-version.py"`. Скрипт ничего не меняет: берёт версию, на которой работает эта сессия, версию, установленную для проекта, и последнюю версию в канале — по тегам на GitHub, а без сети — по локальной копии каталога.
2. **Ответ:** перескажи три версии и итог одной-двумя строками. Если доступна новая версия — дай команды обновления из вывода скрипта в блоке кода; если установлена новее работающей — скажи перезапустить Claude Code. Что нового в версии — страница Releases репозитория `Only1S/1c-ai-core` или `RELEASES.md` в нём.
3. **Обновлять сам не начинай** — только по просьбе пользователя.
