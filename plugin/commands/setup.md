---
Подключи текущий проект к ядру ones-core. Говори с пользователем простыми словами, вопросы — окном вариантов.

1. **Узнай три вещи** (одним окном вариантов, рекомендуемый вариант первым):
   - где лежит выгрузка конфигурации (папка `src` с `Configuration.xml` или проект EDT) — предложи найденные рядом папки;
   - какая платформа 1С: перечисли папки `C:/Program Files/1cv8/<версия>/bin` и `C:/Program Files (x86)/1cv8/<версия>/bin`, где есть `1cv8.exe`; если версий несколько — спроси, под какой работает база;
   - есть ли EDT (его сервер нужен не всем проектам) и порт `1c-toolkit` (по умолчанию 6003; у соседних проектов на этой машине — другой).
   - **языковой профиль**, если в `CLAUDE.md` проекта ещё нет строки «Языковой профиль»: язык кода (английский или русский) и языки синонимов — предложи языки, заведённые в конфигурации (ветка `Languages` выгрузки). Спрашивается один раз (правило `code/language-profile`).
2. **Покажи, что будет сделано:** запусти `python "${CLAUDE_PLUGIN_ROOT}/tools/setup/connect-project.py" --src "<выгрузка>" --platform-bin "<bin>" --toolkit-port <порт> [--edt-port <порт>] --plugin-data "${CLAUDE_PLUGIN_DATA}" --dry-run` и перескажи список простыми словами.
3. **После «да»** — тот же вызов без `--dry-run`. Если профиль спрашивался — допиши в `CLAUDE.md` проекта строку «**Языковой профиль:** код и имена — <язык>; синонимы, представления и `НСтр` — <языки>; комментарии — по-русски».
4. **Программы инструментов** (индекс кода, проверка модулей, справка по платформе, сервер форм, движок тестов YAXUnit): спроси разрешение на скачивание — около 200 МБ из официальных релизов, суммы сверяются. После «да»: `python "${CLAUDE_PLUGIN_ROOT}/tools/setup/install-tools.py" --dest "${CLAUDE_PLUGIN_DATA}/bin"`. Если проекту нужна веб-публикация баз (скиллы `web-*`), в том же вопросе спроси про библиотеку Python `psutil` (без неё скиллы `web-*` не запускаются); проверка — `python -c "import psutil"`, после «да», если её нет: `python -m pip install --user psutil`.
5. **Фоновый индексатор кода** — без него сервер `code-index` не отвечает на запросы. Он один на машину и следит за выгрузками всех подключённых проектов; шаг 3 уже добавил выгрузку в его список. Спроси разрешение на автозапуск при входе в Windows (файл в папке «Автозагрузка» пользователя, без прав администратора). После «да»: `python "${CLAUDE_PLUGIN_ROOT}/tools/setup/code-index-daemon.py" --plugin-data "${CLAUDE_PLUGIN_DATA}" autostart on`. В любом случае запусти его сейчас: тот же скрипт с `start`; проверка — `status` (выгрузка проекта в состоянии `ready`). Если шаг 3 сообщил, что выгрузку ведёт другой индексатор, — объясни, что сначала нужно остановить его и снять его автозапуск.
6. **Итог:** что сделано, что перезапустить (Claude Code — чтобы подхватились переменные проекта), что осталось сделать человеку (сервер `1c-toolkit` поднимает команда `/ones-core:toolkit`).
